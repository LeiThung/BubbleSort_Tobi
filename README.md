# BubbleSort_Tobi

Sortierung der LEDs

Das Script erzeugt für jede LED eine zufällige Farbe.

Anschließend werden die Farben nach ihrem Rotwert sortiert. Dabei werden immer zwei benachbarte Farben miteinander verglichen. Ist der Rotwert der linken Farbe größer, werden die beiden Farben getauscht.

Dieser Vorgang wird immer wieder durchgeführt, bis die Farben von einem kleinen zu einem großen Rotwert sortiert sind.

Die LEDs zeigen nach jedem Sortierschritt den aktuellen Stand an.
